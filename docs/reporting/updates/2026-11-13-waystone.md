## Verification and limits

Native Editor compilation, resource validation and prefab audit pass. Scripted
runtime checks pass for spawn clearance, relic alarm, extraction cue playback,
repeated interaction, same-seed replay and silent death. Both screenshots are
actual Camera.Render captures on an NVIDIA GTX 1070 Ti, not concept images.
They do not establish frame timing, human readability, movement feel or audio mix.

The initial test XML passed26tests but its overall source gate failed because
optional inference/App UI packages rewrote settings. That failure is retained.
The follow-up removed the unused inference addon, preserving Assistant/Generators
and the user's analytics preference. Tests26/26, resource audit, exact-source
Linux build, Editor smoke and packaged-player smoke now pass.
